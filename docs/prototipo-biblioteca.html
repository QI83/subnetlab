VLANs

Trunk: levar várias VLANs
por um cabo

Sem trunk, cada VLAN precisaria de um cabo até o roteador — um prédio com 12 setores viraria 12 cabos.
A ideia central

Um link trunk carrega quadros de várias VLANs ao mesmo tempo e marca cada um com a VLAN de origem. A marcação é o tag 802.1Q, inserido dentro do quadro. Porta de acesso não marca nada: ela já pertence a uma VLAN só. Quem decide se a porta é acesso ou trunk é a configuração, não o cabo.

A analogia

Porta de acesso é carta entregue na mão, um destino só. Trunk é o caminhão da transportadora: várias caixas de destinos diferentes no mesmo veículo, cada uma com etiqueta.

Onde a prova cobra
  • Native VLAN viaja sem tag. Se os dois lados discordam, o tráfego cai na VLAN errada — native VLAN mismatch.
  • Trunk não cria VLAN: ela precisa existir nos dois switches.
  • Por padrão o trunk permite todas; restringir é allowed vlan.
No equipamento
interface Gi0/1
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99
